# Space Guardians

Defoldを使用して個人制作した、2Dシューティングゲームです。

文化祭で大人の方にも気軽に遊んでもらえるゲームを目指し、
昔ながらのゲームをイメージしたドット調のグラフィックと、シンプルな操作性を意識して制作しました。

次々と出現する敵を倒しながら、より高いスコアを目指します。

ブラウザ版を公開しているため、インストール不要でプレイできます。

## 工夫した点

### スコアに応じて変化する敵の出現

ゲーム開始直後は基本的な敵が中心に出現し、
獲得したスコアが増えるにつれて新しい種類の敵が出現するようにしました。

敵ごとに移動方法や攻撃方法を変更することで、
ゲームが進むにつれて難易度が上昇するよう設計しています。

### 複数種類の敵キャラクター

クラゲ、ヘビ、UFOなど、異なる特徴を持った敵を実装しました。

敵ごとに個別のスクリプトを用意し、
移動速度、耐久力、攻撃方法などを変更しています。

また、一部の敵は一定時間ごとに複数方向へ弾を発射するなど、
それぞれ異なる行動を行います。

<!-- スクリーンショットを追加 -->

---

### 徐々に激しくなるゲーム展開

敵の出現間隔や出現する敵の種類をスコアによって変化させ、
プレイを続けるほど画面内の敵や攻撃が増えていくようにしました。

単純な操作で遊べる一方で、
高いスコアを目指すほど難しくなるゲームバランスを意識しています。

### ドット調のビジュアル

文化祭で大人の方にも遊んでもらうことを想定し、
昔のアーケードゲームをイメージしたドット調のデザインを採用しました。

複雑なルールを覚えなくても短時間で遊べる、
シンプルなシューティングゲームを目指して制作しています。
